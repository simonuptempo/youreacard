# Card backs for printing

Each file is 825 × 1125 px at 300 dpi: a poker-size card (2.5" × 3.5") plus a 1/8" bleed on every side.
Keep important art inside the inner gold frame; the outer 1/8" gets trimmed off.

- back-A-mirrored.png — Gem Heist on top, You're a Card upside down underneath, so it reads either way up.
- back-B-gem-heist.png — Gem Heist in the middle, You're a Card as the maker's mark at the bottom.
- back-C-yellow.png — option B on the app icon's yellow.

Rebuild with tools/make_gem_heist_logo.py and tools/make_card_backs.py (font: Corben Bold, from Google Fonts).
