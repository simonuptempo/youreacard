GEM HEIST - print files for MakePlayingCards.com

Every image is 822 x 1122 pixels at 300 dpi: MakePlayingCards' poker size, bleed included
(they trim about 36 pixels off each edge).

  fronts/front-01 ... front-89   one file per card in the deck (duplicates included, so 7 Heists = 7 files)
  fronts/front-90-how-to-play    the rules card: how a turn works
  backs/back-01 ... back-89      the card back (design B), one copy per card
  backs/back-90-card-guide       the rules card's other side: every action and Defense

The rules card has its own back, so keep it out of the shuffled deck.

How to order
 1. Go to makeplayingcards.com, choose Game Cards, poker size (2.5" x 3.5", 63 x 88 mm).
 2. Pick a deck of 90 cards.
 3. Fronts: choose "different images" and upload the 90 files in fronts/.
 4. Backs: choose "different images" and upload the 90 files in backs/.
    The numbers line up: front-90 pairs with back-90.
 5. Review the proof: everything important should sit inside the red safe-area line.
