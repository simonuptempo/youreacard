GEM HEIST - print files for MakePlayingCards.com

Every image is 822 x 1122 pixels at 300 dpi: MakePlayingCards' poker size, bleed included
(they trim about 36 pixels off each edge).

  front-01 ... front-89   one file per card in the deck (duplicates included, so 7 Heists = 7 files)
  front-90                a Quick Reference card, so the deck fills a 90-card order exactly
  back.png                the card back (design B), the same on every card

How to order
 1. Go to makeplayingcards.com, choose Game Cards, poker size (2.5" x 3.5", 63 x 88 mm).
 2. Pick a deck of 90 cards.
 3. Fronts: choose "different images" and upload all 90 front files. They're numbered,
    so they stay in deck order.
 4. Backs: choose "same image" and upload back.png.
 5. Review the proof: everything important should sit inside the red safe-area line.
